The Acrolls docs chrome — the layout shell, sticky header, sidebar navigation
drawer, table-of-contents rail, breadcrumbs, pagination, search dialog, theme
toggle, page-actions rail, and page-feedback components, together with their
layout/UI/search styling — is a Svelte port of the UI layer of Blume. It has
been re-namespaced to Acrolls (custom properties `--acrolls-docs-*`, data
attributes `data-acrolls-*`, element ids `#acrolls-content`), de-branded,
stripped of utility-class dependencies, re-pointed at Acrolls' own mdsvex
output, and wired to the Acrolls navigation/content data layer and theme
system. Blume's article prose styling, hotlinked web fonts, machine-readable
island custom elements, internationalization switcher, and AI/MCP/EPUB export
surfaces were **not** carried over.
