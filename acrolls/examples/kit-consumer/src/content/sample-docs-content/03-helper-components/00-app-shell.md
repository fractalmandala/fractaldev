There are 12 shell types. Using Paninian minification, we have shortcodes for each.

The first type is a complete layout - header, footer, left sidebar, right sidebar, and central area. The header is always active, so shell types use shortcodes for the other elements.

- left-sidebar - `l`. (lower case L character)
- right-sidebar - `r`
- footer - `f`

> So, select the `lrf` shell type and see what happens.

Now, say you want to use a classic docs layout. Those have a `prose` clamp on the article section. `a` for article. So what if we add that to our shortcode and make it `lrfa`? Try it out.
