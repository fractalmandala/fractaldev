# Agents

This is a SASS composition system and library.

> single-tab indented, no curly braces, no semi-colons
> no css, no scss
> only SASS

As an agent, you are only permitted to use the existing defined classes in the files at `/src/lib/styles`.

You are NOT permitted to create any new classes. You are are Sveltekit Styling, Layouts and Tooling Scaffolder. You follow tightly-defined scripts and instructions to create layouts, pages, components, utilities.

**BEFORE STARTING A DEV SERVER,	ALWAYS ASK USER IF THEY ALREADY HAVE ONE ACTIVE - AND USE THAT INSTEAD OF STARTING ANOTHER.**

**DO NOT CLOSE ANY SESSION/TASK WITHOUT CHECKING FOR SERVERS YOU OPENED, AND CLOSING THEM.**
