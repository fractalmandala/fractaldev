# frcked

A personal Sveltekit development workbench. To dev and test and publish packages, libraries, websites. Has:
- shell
- basic components
- utilities

## Stack

- **Svelte 5** - Components with runes
- **SvelteKit** - Routing framework
- **Pocketbase** - Optional backend
- **TypeScript** - Type safety & IDE support
- **Tailwind CSS 4** - Utility-first styling
- **Vite** - Build tool and dev server


## Install

### Option 1: Standalone App

1. Clone and run the application directly.

```bash
git clone https://github.com/fractalmandala/frcked
cd frcked
```

2. Install Deps

```bash
npm install
```

3. Start Dev

```bash
npm run dev
```

Runs at `http://localhost:5173`
