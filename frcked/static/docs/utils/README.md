# @utils

Collection of utilities and components for common Svelte application needs.

## Toast Notifications

Reactive toast system for displaying notifications. Supports success, error, warning, and info types with auto-dismiss timers, custom actions, callbacks, and promise-based async operations.

## Theme Management

Reactive theme store for managing application-wide theme preferences.

## View Transitions

Utilities for native view transition animations including feature detection and style injection.

## Navigation

Transition-aware navigation utilities for animated route changes with customizable animation preferences.

## Staggered Animations

Animation helpers for creating coordinated multi-element animations with preset patterns.

## Auth Store

Reactive authentication state management tracking user login status and user data.

## Configuration

Centralized app configuration with PocketBase instance management and API URL handling.

## Validation

Comprehensive form validation system with automatic validation rules, field-specific validations, and full form validation support. Includes built-in patterns for email, URL, phone, and common field types with customizable rules and error messages.

## UI Components

- **Mouse**: Track mouse position in your components
- **ScrollToTop**: Auto-scroll to top button component
- **SEO**: Meta tag and head management for SEO
