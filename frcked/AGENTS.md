# Agents

This is a project to test Sveltekit things, run demos, etc.

> All styling must ONLY be in single-tab indented SASS. CSS or SCSS are not permitted.
> You cannot create new styling classes.
> You cannot write your own styling definitions in any file, `<style>` tag or inline via `style=`. 
> You can only use and work with the existing styles defined in the sass files in `frcked/src/lib/styles` folder. 
> You can learn and understand styling with these at `fractalstyler/configurations-api.md` and `fractalstyler/configurations.md`
